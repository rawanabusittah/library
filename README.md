# اقرأ وارتقِ — المكتبة الإلكترونية

موقع PHP + MySQL لمكتبة كتب مجانية.

## الموقع المباشر

[الرئيسية — اقرأ وارتقِ](http://eqraa.free.je)

المشروع مستضاف على InfinityFree.

## البنية

```
index.php            الرئيسية (الهيرو، من نحن، الأقسام، المميّز، التواصل)
proxy-image.php      وسيط لعرض أغلفة Google Drive
includes/            header, footer, data (الأقسام), icons (أيقونات الأقسام), helpers, db
pages/               categories.php, category.php?c=<قسم>, authors.php
admin/               login.php, dashboard.php
assets/css/          styles.css (الموقع), admin.css (لوحة المدير)
assets/js/           main.js, theme.js, auth.js, admin.js
assets/img/          hero.jpg, covers/, authors/
database/schema.sql  جداول قاعدة البيانات
```

## التشغيل

1. استورد `database/schema.sql` في MySQL (أو أبقِ قاعدتك الحالية فهي بنفس الأعمدة).
2. عدّل بيانات الاتصال في `includes/db.php`.
3. ضع الصور: `assets/img/hero.jpg` و`assets/img/covers/` و`assets/img/authors/`.

## قياس الوصولية والأداء

قياس مبدئي للصفحة الرئيسية على `http://localhost/Library/` باستخدام Chromium في 25 أكتوبر 2026. النتائج محلية وتتأثر بالجهاز والتخزين المؤقت والشبكة:

| المقياس | سطح المكتب (1365×900) | الهاتف (390×844) |
|---|---:|---:|
| فحوص الوصولية الهيكلية المخصصة | 10/10 — 100% | 10/10 — 100% |
| فحوص الأداء السريعة المخصصة | 3/4 — 75% | 3/4 — 75% |
| DOMContentLoaded | 87 ms | 74 ms |
| اكتمال التحميل (`load`) | 133 ms | 129 ms |
| الموارد المنقولة في القياس | نحو 750 KB | نحو 750 KB |

**طريقة الاحتساب والنتائج:**

- الوصولية: عشر فحوص آلية محدودة للتحقق من لغة الصفحة واتجاهها، معالم `main` والتنقل، رابط تجاوز المحتوى، وجود عنوان رئيسي واحد، تسميات حقول النماذج، النصوص البديلة للصور، والأسماء المتاحة للأزرار والروابط. اجتازت الصفحة الفحوص العشرة.
- الأداء: نقطة لكل شرط من الآتي: `DOMContentLoaded` دون ثانية، `load` دون 2.5 ثانية، تحميل مسبق لصورة الواجهة، وصورة واجهة لا يتجاوز حجمها 200 KB. اجتازت الصفحة الشروط الثلاثة الأولى؛ حجم `assets/img/hero.jpg` المقاس 659,534 بايت، لذا لم يجتز الشرط الرابع.
- أُعطيت أربع صور أسفل الصفحة التحميل الكسول (`loading="lazy"`)، بينما تُحمّل صورة الواجهة مسبقاً. أحجام الموارد والأزمنة المرصودة محلية وليست قياساً ممثلاً لاستضافة الإنتاج.

هذه نسب فحوص داخلية معلنة وليست درجات Lighthouse أو تدقيقاً كاملاً لمعيار WCAG. لم يشمل القياس تباين الألوان لكل الحالات، أو اختبار قارئ شاشة، أو قياسات Web Vitals ميدانية. يوصى بضغط صورة الواجهة ثم إعادة القياس، وتشغيل Lighthouse واختبارات يدوية قبل اعتبار الوصولية مكتملة.

## إضافة قسم جديد

أضف سطراً في `includes/data.php` وأيقونة بنفس الـ slug في `includes/icons.php`، وأنشئ جدولاً له.
