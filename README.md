# 📚 المكتبة الإلكترونية الثنائية اللغة
## E-Library Bilingual Website

موقع إلكتروني متكامل لمكتبة رقمية تدعم اللغة العربية والإنجليزية بشكل كامل.

### ✨ الميزات الرئيسية

#### 🌐 دعم اللغتين
- تبديل سلس بين العربية والإنجليزية
- واجهة متكاملة RTL للعربية و LTR للإنجليزية
- حفظ اللغة المفضلة

#### 📚 الأقسام الخمسة للكتب
1. **الروايات** - روايات عربية وعالمية
2. **الكتب الدينية** - كتب إسلامية وديانات
3. **الكتب الطبية** - كتب صحية وطبية
4. **الكتب البرمجية** - كتب برمجة وتكنولوجيا
5. **كتب الأطفال** - قصص تعليمية

#### 🎨 التصميم الكلاسيكي
- ألوان دافئة: بني، بيج، ذهبي
- خطوط عربية أنيقة (Cairo Font)
- واجهة سهلة الاستخدام
- متجاوب تماماً (Responsive)

#### 👨‍💼 أقسام إضافية
- **من نحن**: معلومات عن المكتبة والرؤية والرسالة
- **المؤلفون**: معلومات عن المؤلفين المتعاونين
- **تواصل معنا**: نموذج للاستفسارات والاقتراحات

#### 🔐 لوحة تحكم المدير
- إضافة/تعديل/حذف الكتب
- إضافة تصنيفات جديدة
- إدارة الرسائل المستلمة
- واجهة سهلة وبديهية

### 🚀 كيفية الاستخدام

#### للمستخدمين العاديين:
1. افتح `index.html` في المتصفح
2. استكشف أقسام الكتب الخمسة
3. اقرأ "من نحن" لمعرفة المزيد عن المكتبة
4. تعرف على المؤلفين المتعاونين
5. أرسل استفسارات أو اقتراحات
6. بدل اللغة من خلال الزر في الأعلى

#### للمدراء:
1. افتح `admin.html`
2. أضف كتب جديدة بملء النموذج
3. عدل أو احذف الكتب الموجودة
4. عرض الرسائل المستلمة

### 💾 التخزين المحلي

الموقع يستخدم `localStorage` للتخزين المحلي:
- حفظ الكتب المضافة
- حفظ اللغة المفضلة
- حفظ الرسائل المستلمة

### 🗄️ قاعدة البيانات

لاستخدام قاعدة بيانات MySQL:
1. أنشئ قاعدة بيانات جديدة
2. شغل كود SQL من `database.sql`
3. اربط الموقع بالخادم (Express/Node.js)

### 🔧 المتطلبات التقنية

- متصفح حديث يدعم ES6+
- لا توجد متطلبات خارجية (يعمل بدون إنترنت مع localStorage)
- اختياري: Node.js و Express للخادم

### 📱 الاستجابة

الموقع يعمل بشكل مثالي على:
- ✅ أجهزة الهواتف الذكية (320px+)
- ✅ الأجهزة اللوحية (768px+)
- ✅ أجهزة سطح المكتب (1024px+)

### 🎯 المميزات المستقبلية

- تكامل مع قاعدة بيانات حقيقية
- نظام تسجيل دخول للمستخدمين
- التقييمات والتعليقات على الكتب
- قائمة الكتب المفضلة
- بحث متقدم
